Roadmap

Planned development from November 2026 to December 2028. Each phase begins when the previous gate is met; dates are provisional.

Current phase Foundations Nov 2026 – Feb 2027
  • Steering committee formed
  • Reference process agreed with Mathlib and CSLib
  • Cross-library index
Gate: first reference set agreed
Pilots Mar – Aug 2027
  • Canonicity and quality pilot on a first library
  • Search pilot on a second library
  • First hand-checked bridges
Gate: divergences found and fixed in the first pilot
Expansion Sep 2027 – Feb 2028
  • CI actions for all participating libraries
  • Agent-synthesized bridges
  • Cryptography library built with the tools
Gate: three libraries run the tools in CI
Scale Mar – Dec 2028
  • Public benchmarks and datasets
  • Bridges upstreamed to Mathlib and CSLib
  • Annual workshop on reference definitions

Measures of success

  • Libraries running the tools in CI
  • Divergent definitions found, and the share fixed or bridged
  • Bridges merged and upstreamed to Mathlib or CSLib
  • Duplicate formalizations avoided through search
  • Findings rejected by maintainers, kept low
