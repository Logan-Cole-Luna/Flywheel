Tools

Five tools share a single index of declarations drawn from all participating libraries.

1 Semantic search

Finds definitions and theorems across libraries by content. Unlike existing Lean search engines, it indexes several libraries together, and a match is reported as equivalent only after an agent has proved the equivalence in Lean.

2 Canonicity checking

Compares a definition with an agreed reference, taken from Mathlib or CSLib where one exists and otherwise proposed by domain experts.

3 Harmonization

Synthesizes bridge lemmas between equivalent definitions, stating any overhead such as a quadratic simulation. Bridges are proposed to both libraries as pull requests.

4 Proof quality

Scores proofs for robustness to upstream changes, generality, size and build time, and reuse, and suggests specific improvements.

5 Faithfulness checking

Tests whether an informal statement was formalized correctly, combining back-translation, independent AI judges, and canonicity checks. It builds on AIProver.
