Get involved

Contributions from library developers, tool developers, and domain experts are welcome.

Ways to contribute

  • Library teams: run the tools in CI and report what they miss.
  • Domain experts: propose and review reference definitions.
  • Tool developers: work on search, canonicity, bridge synthesis, or proof quality. [TBD: repository]
  • Sponsors: support compute, engineering, and events.

Discussion

A Flywheel channel on the Lean Zulip is being set up. [TBD: link] Tutorials, workshops on reference definitions, and events through Georgia Tech’s CCAAIM are planned.
